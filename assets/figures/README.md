# Figure provenance

`mask_correction_comparison.png` is generated by
`scripts/make_readme_mask_figure.py` from the locked Experiment-15 binary mask
artifacts. No source RGB frame is redistributed.

The displayed source is near the median of the 30 source-level downstream
gains, rather than the documented +14-dB outlier. Distance and proposed masks
use the same registered per-frame added-pixel budget. Colors are computed from
the masks and removal-support GT; they are not hand painted.
